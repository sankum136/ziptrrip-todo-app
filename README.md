# Ziptrrip Todo Application

## Technologies
- React
- Node.js
- Express
- Axios

## Features
- Add Todo
- View Todos
- Edit Todo
- Delete Todo
- Mark Complete/Pending
- Todo Details Page

## Installation

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## API Endpoints
- GET /todos
- GET /todos/:id
- POST /todos
- PUT /todos/:id
- DELETE /todos/:id
